# Bundled fonts

All four families are licensed under the SIL Open Font License 1.1, which
permits bundling and redistribution inside an application. They are self-hosted
rather than linked because the app's webview blocks external requests and has no
network at first paint.

Regenerate with `python scripts/fetch-fonts.py`.
